ثبت مسیر صفحات بازدیدشده کاربران و خروجی XLSX با یک ردیف برای هر کاربر.

== نصب ==
1. فایل ZIP را از مسیر افزونه‌ها > افزودن > بارگذاری افزونه نصب کنید.
2. افزونه را فعال کنید.
3. گزارش‌ها از منوی «مسیر کاربران» در مدیریت وردپرس در دسترس است.

== ساختار خروجی ==
ستون اول شناسه ناشناس کاربر است. ستون‌های بعدی بازدید 1، بازدید 2 و ... هستند.
هر سلول بازدید شامل JSON با url، referrer، timestamp، browser و device است.

== حریم خصوصی ==
این افزونه IP، نام، ایمیل یا اطلاعات فرم را ذخیره نمی‌کند، اما شناسه ناشناس و تاریخچه صفحات می‌تواند داده تحلیلی محسوب شود. متن سیاست حریم خصوصی و سازوکار رضایت کوکی سایت را متناسب با قوانین محل فعالیت به‌روزرسانی کنید.

== محدودیت‌ها ==
نگهداری پیش‌فرض داده‌ها 365 روز است. نسخه 1.2 بازدیدهای معوق را به‌صورت گروهی و با یک کوئری ثبت می‌کند، ثبت‌های تکراری را بدون SELECT اضافه کنار می‌گذارد و مدیران سایت و ربات‌های شناخته‌شده را ثبت نمی‌کند.
********
برای سایت‌های پرترافیک (بالای ۱۰۰ هزار بازدید روزانه)، بهتر است دوره نگهداری داده‌ها (uj_retention_days) کاهش یابد تا دیتابیس سنگین نشود.
راه حل: حتماً روی جدول دیتابیس قابلیت پاکسازی دوره‌ای دوره (مثلاً نگه داشتن داده‌های ۳۰ یا ۶۰ روز اخیر به‌جای ۳۶۵ روز) را در تنظیمات افزونه پیشنهاد میکنم:
add_filter('uj_retention_days', function() { return 60; });
