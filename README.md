# افزونه User Journey

افزونه‌ای سبک برای ثبت مسیر صفحات بازدیدشده کاربران در وردپرس و دریافت گزارش به‌صورت فایل Excel.

هر کاربر با یک شناسه ناشناس شناسایی می‌شود و بازدیدهای او به‌ترتیب در گزارش ثبت خواهند شد.

## قابلیت‌ها

* ثبت مسیر صفحات بازدیدشده کاربران
* اختصاص شناسه ناشناس به هر کاربر
* ثبت آدرس صفحه و Referrer
* ثبت تاریخ و ساعت بازدید
* تشخیص مرورگر و نوع دستگاه
* دریافت خروجی استاندارد XLSX
* قرار دادن تمام بازدیدهای هر کاربر در یک ردیف
* جلوگیری از ثبت بازدیدهای تکراری
* ثبت گروهی بازدیدهای معوق با یک کوئری
* عدم ثبت فعالیت مدیران سایت
* عدم ثبت ربات‌های شناخته‌شده
* پاک‌سازی خودکار داده‌های قدیمی

## نصب افزونه

1. فایل ZIP افزونه را دانلود کنید.
2. وارد پیشخوان وردپرس شوید.
3. به مسیر «افزونه‌ها ← افزودن افزونه تازه» بروید.
4. روی «بارگذاری افزونه» کلیک کنید.
5. فایل ZIP را انتخاب کرده و افزونه را نصب کنید.
6. پس از پایان نصب، افزونه را فعال کنید.
7. گزارش‌ها از منوی «مسیر کاربران» در مدیریت وردپرس در دسترس خواهند بود.

## ساختار فایل خروجی

ستون اول فایل Excel شامل شناسه ناشناس کاربر است. ستون‌های بعدی با عنوان «بازدید ۱»، «بازدید ۲» و به همین ترتیب ایجاد می‌شوند.

هر سلول بازدید شامل اطلاعات زیر با فرمت JSON است:

  "device": "Desktop"

## حریم خصوصی

این افزونه اطلاعات زیر را ذخیره نمی‌کند:

* آدرس IP
* نام و نام خانوادگی
* ایمیل
* شماره تماس
* اطلاعات واردشده در فرم‌ها

بااین‌حال، شناسه ناشناس کاربر و تاریخچه صفحات بازدیدشده ممکن است طبق قوانین محل فعالیت سایت، داده تحلیلی محسوب شوند.

پیشنهاد می‌شود متن سیاست حریم خصوصی و سازوکار رضایت کوکی سایت را متناسب با قوانین محل فعالیت خود به‌روزرسانی کنید.

## نگهداری و پاک‌سازی اطلاعات

دوره نگهداری پیش‌فرض اطلاعات در افزونه ۳۶۵ روز است. داده‌های قدیمی پس از پایان این دوره به‌صورت خودکار از جدول افزونه پاک می‌شوند.

برای سایت‌های پرترافیک، به‌خصوص سایت‌هایی با بیش از ۱۰۰ هزار بازدید روزانه، بهتر است دوره نگهداری اطلاعات به ۳۰ یا ۶۰ روز کاهش پیدا کند تا حجم دیتابیس بیش‌ازحد افزایش نیابد.

برای تنظیم دوره نگهداری روی ۶۰ روز، کد زیر را در فایل `functions.php` قالب فرزند یا یک افزونه اختصاصی قرار دهید:

</div>

```php
add_filter('uj_retention_days', function () {
    return 60;
});
```

برای نگهداری اطلاعات به‌مدت ۳۰ روز نیز می‌توانید مقدار `60` را به `30` تغییر دهید.

## بهینه‌سازی‌های نسخه 1.2.0

* ثبت گروهی بازدیدهای معوق تنها با یک کوئری
* جلوگیری از ثبت‌های تکراری بدون اجرای `SELECT` اضافه
* حذف خودکار اطلاعات قدیمی براساس دوره نگهداری
* نادیده گرفتن بازدید مدیران سایت
* نادیده گرفتن ربات‌های شناخته‌شده
* کاهش تعداد درخواست‌ها و فشار واردشده به دیتابیس

## نکات مهم

* فعال‌بودن JavaScript در مرورگر کاربر برای ثبت بازدیدها ضروری است.
* پاک‌کردن کوکی‌ها ممکن است باعث ایجاد شناسه ناشناس جدید برای کاربر شود.
* استفاده از سیستم‌های کش یا CDN ممکن است به تنظیمات تکمیلی نیاز داشته باشد.
* پیش از استفاده در سایت اصلی، افزونه را در محیط آزمایشی بررسی کنید.
* برای سایت‌های پرترافیک، دوره نگهداری کوتاه‌تر توصیه می‌شود.
